COJ selectors: tag=, form=, lemma=, and phon=. Use __ for any node. Multiple attributes on one node must be grouped in brackets, for example [form=no & phon=PHON].

This editor supports the flat core of TGrep2 patterns; grouped subpatterns and named-node backreferences are not included.
